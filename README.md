# 🕌 Buku Sholawat - Kitab Sholawat Digital Embongan Oleh Hidayah

Aplikasi web sederhana, ringan, dan responsif untuk membaca, mengelola, dan menyimpan koleksi sholawat. Dibangun dengan arsitektur **serverless** (tanpa biaya hosting database) menggunakan GitHub Pages, Google Apps Script, dan Google Sheets.

> *"Lantunan cinta, sejuk di hati."*

---

## ✨ Fitur Utama

- 🔍 **Pencarian & Filter**: Cari berdasarkan judul/kategori, urutkan berdasarkan Terbaru, Terlama, A-Z, atau Favorit.
- 🌙 **Mode Malam (Dark Mode)**: Tampilan nyaman untuk membaca di malam hari.
- 📝 **Rich Text Editor**: Tambah sholawat baru dengan formatting lengkap (rata kiri/kanan/tengah, list nomor/bullet, tabulasi, bold, italic, embed gambar, dan link).
- 🎵 **Audio Embed**: Support pemutaran audio langsung dari link MP3, TikTok, YouTube, atau SoundCloud.
- 🔐 **Sistem Auth Aman**: Login menggunakan nomor HP yang telah didaftarkan di database (tidak ada auto-register sembarangan).
- 🏷️ **Badge NEW**: Penanda otomatis untuk sholawat yang baru ditambahkan dalam 7 hari terakhir.
- 📱 **Responsive**: Tampilan optimal di desktop maupun perangkat mobile.
